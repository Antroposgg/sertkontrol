# data/demo — демо-источники N и N+1 (владелец R1)

**Статус:** этап 1. Сейчас каталог пуст, кроме этого README; копируется в образ в `/opt/sertkontrol/demo`.

## Назначение
Вымышленные записи реестра для сценария жюри (АРХ §2): снапшот N и N+1, где у части документов меняется статус. Из них `ingest --demo` собирает пару снапшотов.

## Правила
- Данные ТЕСТОВЫЕ и так помечаются в карточке, на экране «Данные» и в README (КЕЙС §2 п.10).
- Никаких персональных данных: наименования — «ТЕСТОВЫЙ …», ИНН — вымышленные с верной контрольной цифрой (АРХ §7.7).
