# apps/certd/bot — диалоги бота MAX (владелец R4)

**Статус:** этап 1 (карточка, кнопки «на контроль»), этап 2 (уведомления). Не реализовано.

## Назначение и границы
- Делает: разбор событий webhook, ответы и кнопки по таблице «Интерфейс бота» (АРХ §8), callback payload `<действие>:<id>`.
- НЕ делает: доменную логику — только через `DomainService` (C6), поэтому бот и мини-приложение показывают одинаковый вердикт. Транспорт — `libs/maxapi`.

## Зависимости
`apps/certd/domain.hpp` (C6), `libs/maxapi`. Живёт в бинаре `certd`.

## Инварианты
Сообщения ≤ 4000 символов; особых кнопок ≤ 3 в ряду; payload — id записи в БД, а не номер (лимит длины payload в документации MAX не найден).
