# libs/maxapi — клиент Bot API MAX, outbox-отправитель, проверка initData (владелец R4)

**Статус:** этап 1 (initData, webhook), этап 2 (отправитель outbox с token bucket). Не реализовано.

## Назначение и границы
- Делает: вызовы Bot API MAX, двухуровневый token bucket (глобально C=5, r=25/с; на чат C=1, r=1/с — АРХ §7.6), повторы с джиттером на 429/5xx, проверку HMAC initData.
- НЕ делает: доменную логику — только транспорт.

## Правило
Каждое поле и эндпоинт MAX API сверяется с актуальной официальной документацией MAX; непроверенное — за интерфейсом, с фикстурами, в «известных ограничениях» README.

## Контракты
Читает outbox (C9, `docs/contracts/outgoing_message.schema.json`).
