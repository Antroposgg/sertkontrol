# libs/verify — индексы, поиск, правила вердикта (C4, владелец R2)

**Статус:** этап 1 (точный поиск и правила статуса/срока), этап 3 (нечёткий поиск). Сейчас — `sk::fake::check`.

## Назначение и границы
- Делает: `verify::check(snapshot, query)` → `Verdict` с метками «факт / расчёт / рекомендация», «нет в данных на <дату>» с ближайшими номерами, нечёткий поиск по `serial_index` (АРХ §7.2).
- НЕ делает: IO, БД, форматирование сообщений бота (это `apps/certd/bot`).

## Куда добавлять правило вердикта
1. Описать правило в `docs/rules.md` (id, основание: факт/расчёт/рекомендация, условие, текст).
2. Реализовать в `libs/verify` (этап 1: файл правил будет указан здесь).
3. Добавить строку в табличный тест `tests/verify/rules_test`.

## Зависимости
- Зависит от: `sk::contracts`, `libs/canon`, `libs/snapshot`.
- От него зависят: `apps/certd` (DomainService).

## Инварианты
- Чистая функция: без IO, «сегодня» передаётся в `Query::today`.
- Точный поиск проверяет весь `equal_range` и сравнивает полную строку (АРХ §7.2).
- Порог нечёткого поиска: расстояние ≤ 2 при отрыве ≥ 0,5; любое ненулевое расстояние → `Level::kNeedsConfirmation`.
