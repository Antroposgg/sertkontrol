# libs/canon — канонизация и грамматика номера (C1, владелец R2)

**Статус:** этап 1 (не реализовано). До этого потребители используют `sk::fake::canonicalize/parse/key_hash/find_numbers`.

## Назначение и границы
- Делает: каноническая форма номера (АРХ §7.1), разбор грамматикой (вид, серия, год), `key_hash` (XXH3, seed 0), выделение до 20 кандидатов из текста.
- НЕ делает: поиск и расстояния (это `libs/verify`), IO.

## Публичный интерфейс
Реализует `sk::canon` из `libs/contracts/include/sertkontrol_contracts.hpp`. Цель CMake — `sk::canon` (план).

## Зависимости
- Зависит от: `sk::contracts`, `libxxhash-dev`.
- От него зависят: `libs/snapshot` (R1, при сборке), `libs/verify` (R2, при поиске).

## Инварианты и «почему так»
- Цифры не трогаются: 0/O различает нечёткий поиск (АРХ §7.1).
- Любое изменение правил поднимает `canon::kVersion`; `certd` не открывает снапшот другой версии.
- Golden-файл `tests/canon_golden.tsv` начинается с трёх строк из АРХ §7.1 и меняется только вместе с `kVersion` и записью в docs/changelog-contracts.md.
