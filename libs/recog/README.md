# libs/recog — распознавание номеров в PDF и изображениях (C5, владелец R3)

**Статус:** этап 1 (QR и текстовый слой, лимиты), этап 4 (OCR, F7). Сейчас — `sk::fake::recognize`.

## Назначение и границы
- Делает: QR (страницы с конца, poppler-cpp + zxing-cpp) → текстовый слой → OCR (Tesseract), в отдельном пуле потоков (ADR-0004).
- НЕ делает: вердикт, скачивание вложений из MAX, сохранение файлов (файлы пользователей не сохраняются — АРХ §6).

## Инварианты
Лимиты `recog::Limits`: ≤ 20 МБ, ≤ 10 страниц, ≤ 25 Мпикселей, ≤ 15 с (АРХ §10).

## Зависимости
- Зависит от: `sk::contracts`, `libpoppler-cpp-dev`, `libzxing-dev`, `libtesseract-dev`.
- От него зависят: `apps/certd`.
