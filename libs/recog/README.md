# libs/recog — распознавание номеров в файлах (C5, владелец R3)

**Статус:** этап 1 — PDF: QR → текстовый слой, лимиты. Фото, OCR и подтверждение — этап 4 (F7).

## Назначение и границы
- Делает: `recog::recognize(bytes, type, limits)` → до 20 найденных номеров (`Found`: сырой текст, источник, ссылка на реестр из QR).
- НЕ делает: вердикт (`libs/verify`), скачивание вложений из MAX (`libs/maxapi`), сохранение файлов — файлы обрабатываются только в памяти (АРХ §6), пул потоков (`apps/certd`).

## Ключевые файлы
| Файл | Что внутри |
|---|---|
| `src/recog.cpp` | Проверка сигнатуры и лимитов, `scan_qr` (poppler 150 dpi gray8 + zxing, страницы с конца, стоп на первой странице с QR), `scan_text` (текстовый слой всех страниц), слияние без дублей |
| `../../tests/fixtures/pdf/*.tex` | Исходники фикстур (pdflatex, T2A + cmap + qrcode); рядом собранные `*.pdf` |

## Публичный интерфейс
`sk::recog::recognize`, `Found`, `Source`, `MediaType`, `Limits` — в контрактном заголовке. Цель CMake — `sk::recog`.

## Порядок и лимиты (ADR-0004, АРХ §10)
1. `size ≤ max_bytes` (20 МБ); иначе `file_too_large`.
2. Только PDF (`%PDF-` в первых 1024 байтах); JPEG/PNG → `unsupported_media_type` с пояснением.
3. Страниц ≤ `max_pages` (10); страница ≤ `max_pixels` (25 Мпикс) при 150 dpi.
4. QR: URL → `registry_url`; номер в тексте QR → `Found{kQr}`.
5. Текстовый слой → `canon::find_numbers` → `Found{kTextLayer}`.
6. Время проверяется между страницами (`timeout`, 15 с) → `number_not_recognized`.
7. Ссылка из QR прикладывается к первому найденному номеру.

## Зависимости
- Зависит от: `sk::contracts`, `sk::canon`, `libpoppler-cpp-dev`, `libzxing-dev`.
- От него зависят: `apps/certd` (DomainService в пуле потоков распознавания).

## Ограничения и отложенное
- Настоящая выписка спайка в репозиторий не входит (персональные данные); фикстура синтетическая, формат QR (ссылка на реестр) — как в АРХ.
- Разбор в подпроцессе с `RLIMIT_AS`/`RLIMIT_CPU` (Should, АРХ §10) — не сделан; падение poppler уронит `certd`. Fuzz-тесты — этап 3.
- OCR и фото — этап 4.
