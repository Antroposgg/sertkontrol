# ADR-0001: Реестр — в собственном неизменяемом снапшоте (mmap)

- Статус: принят
- Дата: 2026-09-26
- Связано: АРХ §6 «Снапшот», §7.2–7.4

## Контекст
Реестр — миллионы записей (N до 2·10⁷), обновляется раз в сутки, читается точечно с целью p99 ≤ 1 мс; нужен суточный diff для уведомлений (F5).

## Решение
`ingest` собирает неизменяемый бинарный файл (формат — `docs/snapshot-format.md`, этап 1), `certd` отображает его в память через `mmap` и держит под `std::atomic<std::shared_ptr>` (`SnapshotHolder`).

## Альтернативы
Таблица в PostgreSQL + `pg_trgm`: сетевой хоп на каждый поиск, нет атомарной версии данных на весь запрос, база растёт на миллионы строк в сутки.

## Последствия
Поиск без сети; атомарная версия данных на весь запрос; diff за O(N) последовательным чтением. Цена — собственный формат, его тесты (roundtrip, fuzz ридера) и версия `canon::kVersion` в заголовке.

## Когда пересмотреть
Понадобятся произвольные аналитические запросы к реестру — тогда дублировать в PostgreSQL.
