# ADR-0010: Явные `{}` у полей агрегатов; `readability-redundant-member-init` выключена

- Статус: принят
- Дата: 2026-09-26
- Связано: CLAUDE.md «Общие правила» (отключение правил линтеров — только через ADR)

## Контекст
GCC 13 с `-Wextra -Werror` (`-Wmissing-field-initializers`) предупреждает, когда designated initializer пропускает поле без инициализатора по умолчанию — даже `std::string`. clang-tidy 18 `readability-redundant-member-init` требует убрать тот же `{}` у полей классовых типов. Настроек, примиряющих обе проверки, в clang-tidy 18 нет.

## Решение
У всех полей агрегатов — явный инициализатор по умолчанию (`{}` или значение). Проверка clang-tidy `readability-redundant-member-init` выключена в `.clang-tidy`.

## Альтернативы
Выключить `-Wmissing-field-initializers` — теряем защиту от неинициализированных полей скалярных типов при добавлении нового поля в контракт. Не использовать designated initializers — хуже читаемость тестов и fake-данных.

## Последствия
Проверка компилятора сохраняется; отключена только косметическая проверка линтера.

## Когда пересмотреть
Если clang-tidy получит опцию игнорировать инициализаторы членов по умолчанию.
