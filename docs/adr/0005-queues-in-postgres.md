# ADR-0005: Очереди, таймеры и outbox — в PostgreSQL

- Статус: принят
- Дата: 2026-09-26
- Связано: АРХ §6 (`outbox`, `job`), §7.5

## Контекст
Нагрузка пилота — десятки пользователей; нужны долговечные очереди, транзакционные с данными.

## Решение
Таблицы `outbox` и `job`, выборка `FOR UPDATE SKIP LOCKED`.

## Альтернативы
Redis, RabbitMQ — ещё один сервис в compose и в эксплуатации.

## Последствия
На один сервис меньше; долговечность и транзакционность — бесплатно.

## Когда пересмотреть
Сотни сообщений в секунду.
