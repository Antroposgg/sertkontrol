# ADR-0006: Авторизация — проверка initData на каждый запрос

- Статус: принят
- Дата: 2026-09-26
- Связано: АРХ §8 «REST», §10 «Безопасность»

## Контекст
Мини-приложение открывается только из MAX и получает подписанную `initData`.

## Решение
Каждый запрос несёт сырую `initData` в заголовке `X-Max-Init-Data`; сервер проверяет HMAC-SHA256 и `auth_date` ≤ 24 ч. Cookie и сессий нет, значит, нет и CSRF.

## Альтернативы
Свои сессии или JWT — состояние, отзыв токенов.

## Последствия
Два HMAC на запрос — микросекунды. На `init_data_expired` мини-приложение просит переоткрыть его из чата (`web/src/api/problem.ts`).

## Когда пересмотреть
Появятся внешние клиенты API вне MAX.
