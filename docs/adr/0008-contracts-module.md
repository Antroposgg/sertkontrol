# ADR-0008: Контрактный заголовок — модуль `libs/contracts`

- Статус: принят
- Дата: 2026-09-26
- Связано: АРХ §1, §3 «Структура», §5 «Контракты»

## Контекст
АРХ называет файл `sertkontrol_contracts.hpp` (C1, C2, C4, C5), но в структуре репозитория §3 не указывает его место. От него зависят все библиотеки, поэтому он не может лежать внутри одной из них без обратной зависимости.

## Решение
`libs/contracts/include/sertkontrol_contracts.hpp` — header-only цель `sk::contracts` без внешних зависимостей. Fake-реализации контрактов — рядом, отдельной целью `sk::fakes` (`sertkontrol/fakes.hpp`) в пространстве имён `sk::fake`. C6 (`apps/certd/domain.hpp`) остаётся в `certd`, как в АРХ, потому что зависит от Drogon.

## Альтернативы
Корень репозитория (`include/`) — вне модульной структуры и без README; внутри `libs/canon` — `snapshot` и `recog` получили бы лишнюю зависимость.

## Последствия
Граф зависимостей: `contracts` — лист, на который смотрят все. Изменение файла — изменение контракта (docs/changelog-contracts.md).

## Когда пересмотреть
Если контракты разрастутся — разделить на заголовки по C1…C5 внутри того же модуля.
