# ADR-0011: Зеркало apt в Docker-сборке — аргумент `APT_MIRROR`

- Статус: принят
- Дата: 2026-09-26
- Связано: КЕЙС §4 п.5 (сборка ≤ 5 мин), АРХ §2 (цель ≤ 4 мин), §10 (Dockerfile)

## Контекст
Компиляция занимает ≈ 10 с; остальное время `docker build --no-cache` — скачивание ≈ 175 МБ apt-пакетов. С `archive.ubuntu.com` из РФ сборка заняла 259 с (цель 240 с), с зеркала `mirror.yandex.ru` — 78–92 с. Жюри, VPS и команда — в РФ.

## Решение
`ARG APT_MIRROR` (по умолчанию `http://mirror.yandex.ru/ubuntu`) подставляется в `ubuntu.sources` обеих стадий Ubuntu. CI на GitHub передаёт `http://azure.archive.ubuntu.com/ubuntu`. `compose.yaml` пробрасывает `APT_MIRROR` из окружения.

## Альтернативы
Кеш-маунты apt — `--no-cache` их не сбрасывает, таймер показывал бы не то время, которое увидит жюри на чистой машине. Собственный базовый образ с зависимостями — АРХ §1 отказался от него; кроме того, КЕЙС исключает из лимита только загрузку базовых образов, а не сторонние образы.

## Последствия
Состав пакетов и подпись не меняются: apt проверяет подписи архива Ubuntu независимо от зеркала. Вне РФ можно собрать с `--build-arg APT_MIRROR=http://archive.ubuntu.com/ubuntu`.

## Когда пересмотреть
Зеркало недоступно или медленнее официального архива.
