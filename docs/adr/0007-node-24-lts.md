# ADR-0007: Node.js 24 LTS вместо 20

- Статус: принят
- Дата: 2026-09-26
- Связано: АРХ §3 (таблица сервисов), §10 (Dockerfile); docs/plan.md, противоречие 5

## Контекст
АРХ указывает образ `node:20` для сборки мини-приложения. Node.js 20 закончил поддержку 30.04.2026 — к дате разработки (26.09.2026) он без обновлений безопасности. Актуальные мажорные версии инструментов (Vite 8, Vitest 5, ESLint 10) требуют новый Node.

## Решение
`node:24-slim` в Dockerfile, `node-version: 24` в CI, `"engines": {"node": ">=24"}` в `web/package.json`.

## Альтернативы
Node 22 (поддержка до 04.2027 — впритык к жизни пилота); остаться на 20 — неподдерживаемый рантайм в сборке.

## Последствия
Node используется только при сборке статики; в рантайм-образ не попадает.

## Когда пересмотреть
Конец поддержки Node 24 (04.2028).
